# Interlinears (BLE)

Finished BLE interlinear products for CGV apps.

## Layout

```
interlinears/
  OT/
    *.tokens.jsonl          # one token per line (app-friendly)
    *-NN.interlinear.txt    # chapter files for readers/exports
  NT/
    *.tokens.jsonl
    *-NN.interlinear.txt
```

## Formats

### `*.tokens.jsonl`

One JSON object per token, e.g.:

```json
{"book":"tito","ch":1,"vs":1,"tok":1,"surface":"Παῦλος","lemma":"Παῦλος","morph":"N-----NSM-","es":"Pablo","strongs":"G3972"}
```

Fields may vary slightly by testament; `surface`, `lemma`, `morph`, and `es` are the core.

### `*.interlinear.txt`

Chapter files. Each line:

```text
genesis 1:1	בְּרֵאשִׁית<root|H7225|morph|en·principio> …
```

Token shape: `surface<lemma|Strong's|morph|spanish>`.

## Source

Generated by engines in `herramientas` (MNA + Biblia-BLE). Published here for app consumption.

Do not edit these files by hand in apps — regenerate and re-sync from the engine repos.
